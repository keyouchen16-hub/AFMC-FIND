# 0.8.14 搜索匹配与首批结果（2026-11-05，已安装）

负责人 Codex；工作树 codex/initial-development，无提交/推送。源文件、候选包与安装版曾于本轮完成一致性验证；后续播放器修正见 RELEASE_0815.md。

## 实现

- 通用名称匹配分层先于播放健康状态，排除名称完全不匹配的搜索结果；不为“少林足球”硬编码规则。已有明确中英文别名参与匹配，年份、清晰度、集数等条件影响分层。
- 同匹配层内仍按真实播放证据优先，再按相关度排序；名称匹配不等于文件内容、软件安全性或实际可播证明。
- 查询范围内缓存相关度计算，播放状态保持实时。
- 普通来源并发从三路调整为六路，同主机最多两路；动态浏览器单独一路。可分页来源先上报首批结果，再继续翻页，后续页失败不丢弃已返回结果。
