## 设计判断

当前 MainWindow.xaml 同时存在标题栏、聚合搜索大标题、同名导航、搜索与筛选、重试行；结果三行解释密集，右侧约七个动作并列。需要减少层级并建立主次，而非只调整透明度。

主轴为搜索、判断资源、采取动作。顶部合并品牌/轻导航/窗口控制；搜索占独立一行；筛选与结果统计一行。结果列表保留独立数值列，选中后在右侧查看详情。原始文件名、匹配理由、复制与来源入口按需展开。来源管理仍可进入，不恢复历史/收藏/来源状态等独立主屏按钮。

## 建议尺度（WPF采用DIP，预览采用CSS像素）

| 元素 | 建议 |
|---|---|
| 外边距/组间距 | 24 / 16，细节采用4/8/12步进 |
| 标题栏与搜索框 | 44–48高 / 48高 |
| 常用控件/点击图标 | 32高 / 至少32×32操作区，图形16 |
| 列表行 | 72–76高；有图约36×50，无图收起 |
| 字号 | 页面或详情标题20；结果标题14；正文13；辅助12 |
| 列表数值 | 大小约96、日期104、做种56；表头与行共享列宽、右对齐 |
| 详情宽度 | 300–320；更窄窗口按需抽屉，不能靠缩小文字硬塞 |
| 圆角 | 小控件8，搜索12，浮层16；不全做胶囊 |

这些是本项目建议，非Apple规定值。中文沿用Windows系统回退字体，不捆绑Apple字体；Windows窗口控制位置与快捷键保持。后续原生实现需单独验证125%/150%/200%缩放和键盘访问。
