# AFMC FIND 0.8.4 播放器验收

## 搜索结果与实际下载

搜索结果的做种数是来源报告值。路由节点负责发现资源节点。取得种子元数据后，提供完整文件需要整个资源的分片可获得，边播则需要解码器当前请求的分片。长时间拿不到文件列表、或者取得部分分片后持续停滞，都可能发生。单个时刻的 0 KB/s 无法判定永久失效。

所选结果有磁力和同哈希的种子地址时，优先尝试验证后的种子文件。尝试时间限制为两秒。失败或内容不符会回到原磁力校验。播放分片先取当前附近，再将空闲请求用于更远的后续片段。没有对本次公网慢资源测得可控的前后速度差异。

## 窗口与字幕

播放后收起输入栏；单文件视频省略选集栏。全屏隐藏外框、标题、状态、常驻控制栏，移到屏幕底部显示操作。验收对比 WPF 视频控件与窗口的实际宽高，两者差值小于三个独立像素。未逐台测试多显示器、不同缩放率。

在字幕菜单搜索在线字幕，通过 Stremio 插件协议调用 Cinemeta 和 OpenSubtitles v3，不需另外安装播放器。真实联网端到端测试按 Spider-Man 搜索，选择 2002 年作品，获取字幕列表，选英语版本并下载，LibVLC 字幕轨数量增加。影片可按片名或 IMDb 编号搜索，剧集支持 IMDb 编号带季集。字幕服务可用性、语种及版本是否同步取决于具体影片。中文查询“蜘蛛侠”返回十个影片候选，此次 2002 年影片的服务响应未列出中文轨。
