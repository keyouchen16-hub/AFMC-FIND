状态：0.8.0已安装，功能验收通过；安装版截图受前台激活限制未验证。负责人Codex；工作树codex/initial-development，无提交/推送。

## 功能

- 资源详情新增“播放视频”；独立“播放器”入口可粘贴磁力/HTTP(S)视频直链或打开本地.torrent。
- 原生LibVLC播放，支持暂停/继续、拖动进度、音量、全屏、字幕加载和种子内选片；沿用深色磨砂和小圆角控件。
- MonoTorrent按选中视频与读取位置缓冲，磁力元数据获取上限两分钟；无做种可取消，不把缓冲显示为播放成功。
- 关闭/停止结束BT连接，删除此次缓存；启动播放器回收未被占用的异常遗留会话目录，不删除用户文件或活跃会话。
- 下载解码组件与主程序升级分离：首次下载138.5MiB，x64运行文件105.7MiB；本机测试已准备好。固定官方NuGet包SHA256，取消/错误包/路径越界/提取大小均受控。

## 边界

不是云端离线下载；无在线做种、带访问限制或连接失效的资源不能保证播放。网盘分享页、网页、压缩包和非视频种子不作为直接视频播放。第一版直链为HTTP(S)视频文件，不承诺任意HLS/DASH播放列表、DRM或登录态。测试覆盖AVI/PCM与字幕，MP4/MKV/H.264/HEVC等由LibVLC提供能力，未逐一进行真实编码样本验证。
