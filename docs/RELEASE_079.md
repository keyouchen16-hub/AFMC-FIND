## 限制

这是有边界的公开接口发现，不是任意网页万能适配器。没有执行网页JS或浏览器网络捕获，不猜测/获取私有API Key，不绕过账号或验证码。静态页面无可验证入口时明确报告未添加。资源分类来自上游声明，不代表对全站内容逐条核验。650是适配目录数量，不是本轮测通650网站。新增UI未完成所有DPI/多屏矩阵；UIA/路由事件验证不等同物理鼠标全流程。

网络读取限制：75秒发现总时限、20个请求、4MB单响应/20MB总量；重定向及DNS/实际连接目标校验，禁止本机/内网发现，沿用已有系统代理。失败和修复见 `evidence/v079/failures.md`。
