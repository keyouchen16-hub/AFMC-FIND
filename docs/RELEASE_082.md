# AFMC FIND 0.8.2 播放体验验收

上版报告中的下载比例来自轮询发现播放时间前进的时刻。实际检查覆盖点击到播放时钟前进的整段路径，观察时的百分比不等于首帧阈值。

## 行为

双击可播放的搜索结果，播放器打开并自动加载该行。右键选中指针所在行，在菜单中播放、调用下载软件、复制链接或打开来源。菜单沿用详情区的可用状态。空白区域和网盘行不会通过双击启动 BT 播放。

取得文件列表后，立即把选中文件的开头交给解码器。去掉文件尾部的阻塞预读，文件格式需要尾部索引时由解码器自己请求。切集会重置分片请求位置。文件缓存参数改为 300 毫秒，这个值不代表点击到首帧的耗时。

只有哈希的磁力会尝试两个 DHT 引导入口。文件列表到达前显示路由节点数、已连接的资源节点数和传输速度。路由节点帮助查询，只有提供相应资源的节点能交付种子信息和视频分片。

## 复现与验证

- 第一轮安装版复现了用户链接持续 120 秒连接 0 个资源节点。默认引导入口单次 UDP 探针未收到回复，Transmission 引导入口返回带匹配事务标识和节点 ID 的 KRPC 应答。
- 首轮去掉尾部预读后，多集切换回归发现选片窗口仍可能指向旧文件。修复后 46 项播放器专项通过，包括真实解码、拖动、切集、取消和清理。
- 搜索工作台的路由事件测试覆盖结果双击、右键菜单和从菜单启动播放器。测试日志存放在 docs/evidence/v082。
公开磁力实测 122.6 秒，最终 13 个路由节点，0 个已连接资源节点，未取得元数据或播出画面。受控回环磁力从点击到观察到播放时间前进为 3.37 秒。该时间包含连接、元数据获取和轮询，不等于精确的首帧时间。最终播放器专项 48 项、工作台 62 项通过。最终安装校验及安装版直链、暂停、磁力和缓存清理通过，进程 69260。
