## 已复现的原因

用户提供 `https://4kbt.org/category/movie`。旧实现用默认ubuntu验证时失败；改用Hancock实际返回5个磁力，但标题都被详情片名覆盖。分类页部分新标题用完整片名站内搜索也返回零条，例如当时的蜘蛛侠条目。早期根据网页文本认为只有纯文本磁力的判断不完整，实际HTML同时存在磁力锚点，不能作为本例的主要根因。

配置新窗口未挂GlassBackdrop，设置的深色底板又遮挡材质。现在配置/目录/设置均采用系统backdrop=3，共享半透明渐变，统一自绘标题栏和版本标识。
