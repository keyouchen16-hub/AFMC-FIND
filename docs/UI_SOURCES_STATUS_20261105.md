# 搜索源、播放证据与反馈区交互预览

2026-11-05；负责人 Codex。仅设计预览，未修改原生产品代码、版本、安装件或个人配置。安装版沿用上一轮已验证的 0.8.13；本轮未重新做安装验证。

## 目标与结构

- 保持搜索工作台方向，加入有限、可关闭的 120–180ms 状态与页面过渡，不采用持续装饰动画。
- 搜索源页顶部直接粘贴网址识别；下方并列「已添加」「已适配目录」，取消必须进入添加窗口才能浏览目录的层级。
- 公开来源排在需要账号的来源前面；提供名称/类别查询、访问方式和资源类别筛选。已适配不等于当前可连接。
- 已添加来源只常驻启用开关和更多菜单；测试、编辑、打开原站、移除放进该来源自己的菜单。后续原生实施需确认移除对象并可取消。
- 设置保留现有控制，新增反馈邮箱 keyouchen16@gmail.com 和原文 Find the You.；沿用 family-mark，右下角 author-mark 继续提供反馈入口。

## 播放证据设计

区分「近期起播成功」「有数据·起播未确认」「尚未验证」「本次连接超时」，显示证据及检测时间。成功必须来自实际解码；有做种和收到分片均不能代替起播证明。最近成功不承诺全片流畅，本次超时也不等于永久无法下载。

综合推荐优先考虑有效的实际起播证据，再结合相关度等原有指标。检测期间避免列表突然跳动，提示用户应用更新后的排序。下一阶段须接入现有 PlaybackHealth 和有限检测调度，保留超时、取消、证据过期和已准备会话交接规则，不为验证所有结果无限并发下载。

## 原生实施衔接

复用 EngineSourcesWindow 已有 CatalogAsync、分类/访问方式过滤与配置功能，以及 WebsiteDiscoveryWindow 的网址识别逻辑。将目录和管理布局迁回 WPF；不把 HTML 预览当成新运行时。保留私人来源认证信息，不在记录中输出密钥。

本预览没有验证实际网站识别、来源连接或公网电影播放，也没有解决此前的公网电影快速起播问题。真实网络状态、原生焦点、键盘、DPI、多屏、安装回归属于批准实施后的验收。
