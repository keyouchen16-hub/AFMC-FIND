## 改进

- 相同哈希按稳定规则选择主记录，保留原始来源观察值；标题、详情页、图片归属同一记录。大小、年份冲突及字段来源在详情和复制信息中可查。做种数保留来源报告最大值及出处，不当作实时验证。
- 不用冲突记录推断同一影视作品或补图。明确作品身份时可复用保留的原始来源封面并标注出处；没有图仍不占位置。
- 综合推荐增加名称顺序、完整剧名、软件与教程/视频区分；显式年份、季集、版本和分辨率仍优先于做种热度。关键词匹配不再表示身份已经核实。
- 交接前验证资源哈希与磁力/种子一致；缺少关联或启动失败给出明确错误。UI 仍只声称请求打开。
- 发现历史记录快速连续保存时出现短暂文件占用，改为原子替换及有界重试。失败保留原文件和内存状态；最多重试等待 525ms，没有修改系统安全配置。
