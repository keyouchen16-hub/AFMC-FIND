# AFMC FIND 0.8.8 — 同片版本实际试播择优

负责人：Codex。工作树：codex/initial-development，保留原有未提交文件。

## 行为

搜索结果播放按钮、双击、右键播放共用候选流程。保留选中版本，从当前可见结果挑选最多两个同片候选；依据来源标题明确片名、年份，排除元数据冲突、季集、合集、续集、不同上映年份。当前筛选结果和查询中的明确限制保留，所选版本的国语/粤语/中字/双语以及导演剪辑/加长等标记保留。没有可信匹配时只试选中项。

复用 MonoTorrent 3.0.2、LibVLCSharp 3.10.2 和现有原生运行时，没有新增下载引擎或运行时。最多并行两个候选，每个尝试限时 25 秒，整组预算 60 秒（连接/原生播放器退出清理可能增加少量时间）。实际 VLC DecodedVideo 大于零才可胜出；网站报告做种数、DHT 节点数、元数据到达均不是成功依据。选择最先成功解码的已启动候选，取消其他尝试与排队任务。沿用胜出 TorrentPlayback 和缓存，重开视频流交给可见播放器；状态栏显示实际所选版本。

## 边界

这不是全网测速或资源内容鉴定；片名匹配仍依赖来源元数据，且未对没有年份的标题推断同片。第三项排队，因此不宣称得到所有版本的绝对最快值。起播成功不保证整部影片未来不卡顿，缺少做种时不能凭空加速。仅点击播放时试播，不在后台批量下载搜索结果。本轮没有重测用户提供的公网电影磁力，也没有承诺其可用。

手工在独立播放器粘贴链接/打开种子的旧单链接流程保留；自动择优用于搜索结果的播放入口。支持恢复停止、切换和关闭；试播失败不会持久化为永久死种。
